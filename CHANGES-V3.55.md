# Château Grand · V3.55 · Treppenhaus

Das Grand Escalier und die beiden westlichen Geschosstreppen wurden als zusammenhängendes Ensemble ausgearbeitet.

- **Grand Escalier.** Abgestufte Kalksteinprofile an den Setzstufen, ein sandfarbener Fries an den Treppenwangen und modellierte Medaillons an der Stirnseite des Wendepodests. Das obere Galerieprofil nimmt den gleichen Steinfries auf.
- **Kellertreppe.** Durchgehende Kalksteinwangen unter den Läufen, schmiedeeiserne Geländer mit offenen Ovalen und schmalen Messingprofilen. Zwei Opalglaslaternen markieren das Wendepodest.
- **Mansardentreppe.** Durchgehende Eichenwangen, auf das Grand Escalier abgestimmtes Eisen und patiniertes Messing. Zwei Opalglaslaternen beleuchten die Wendung.
- Geometrie-, Lauf- und Türtests prüfen die Übergänge vom Grand Escalier, beide Nebenläufe, Türdurchgänge, Bodenauflage und Kopffreiheit. Eine visuelle Abnahme auf dem iPhone steht aus.

Die ZIP enthält `index.html` auf oberster Ebene für GitHub Pages.

# Château Grand · V3.58 · Außenarchitektur

- Sockel- und Geschossgesimse, Bossen und Eckverbände sind an Hof-, Park- und Seitenfassaden aufeinander abgestimmt.
- Die Rundbögen der Mittelachsen erhalten ein eigenständiges Kalksteinprofil. Rechteckfenster haben profilierte Außenlaibungen und abgestufte Sohlbänke. Die Schmiedeeisenbrüstungen sitzen unterhalb des Glasfelds.
- Die Seiteneinfassungen der Hofterrasse erhalten profilierte Felder und vier modellierte Steinurnen.
- Schmale Metallprofile zeichnen den Knick der Mansarde nach. Die Schornsteinköpfe erhalten eine feinere Abfolge von Steinprofilen.
- Das vollständige Paket enthält die Startdatei `index.html` auf oberster Ebene für GitHub Pages.

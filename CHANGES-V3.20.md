# CHANGES V3.20 – Türbereinigung und echte Hallenkuppel

## Ziel
Zwei konkret erkannte Fehler aus dem Live-Rundgang beheben: eine unpassende Tür an der Treppenwand entfernen und den Deckenmittelpunkt der Halle von einem flachen Ornament zu einer echten räumlichen Kuppelkalotte weiterentwickeln.

## Änderungen
- Westliche Treppenwand im EG geschlossen; die Tür bei x≈-13,21 wurde vollständig entfernt.
- Wandgliederung an dieser Stelle läuft jetzt durch (Sockel, Boiserie, Abschlussprofile).
- Neue flache Vestibülkuppel als 3D-Geometrie im OG mit umlaufendem Kuppelring und innerem Stuckring.
- Zentrale OG-Vestibülzone von flachen Kassetten freigestellt, damit die Kuppel architektonisch lesbar ist.
- Versionskennungen auf `roissy320` / `V3.20` angehoben.

## Bewusste Nicht-Änderungen
- Keine Änderungen an Treppenstufen, Geländern, Außenhülle, Bodenbelägen, Navigation oder Beleuchtung.
- Keine Behauptung einer denkmalpflegerisch gesicherten Originalkuppel; die neue Kalotte ist eine plausible architektonische Ausarbeitung.
